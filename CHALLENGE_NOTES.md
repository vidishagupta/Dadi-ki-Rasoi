# Hacktoberfest 2026 Weekend DEV Challenge: Build for a Friend
**Source URL**: https://dev.to/challenges/hacktoberfest-weekend-2026-10-01

---

## 1. Challenge Overview & Theme
- **Challenge Name**: Hacktoberfest Weekend Challenge: Build for a Friend (Challenge 1 of 5 in Hacktoberfest 2026 DEV Challenges)
- **Core Prompt**: Build something with **open-source AI at its core**. This means running an open-weight model, building on an open-source agent harness/framework, running inference locally, or all three. The open pieces should make the project work.
- **Specific Theme**: **Build for a Friend** — Ship something that solves a real problem for a friend or someone you love. (Explicit prompt inspiration: *"A tool that turns your grandpa's voice memos into a family recipe book. Bonus points if you actually hand it over and tell us what they said."*)
- **Core Narrative Requirement**: Explain **why open innovation matters for what you built**:
  - Runs on a laptop with zero internet (airplane-mode).
  - Keeps intimate family voice notes completely private off external corporate servers.
  - Zero operational/API token costs.
  - Freedom to swap models (e.g., Qwen vs Llama) and customize behavior locally.

## 4. Judging Criteria
1. **Writing Quality** (*Weighted most heavily*):
   - Personal, vivid narrative storytelling.
   - Clear technical explanation without buzzwords.
   - Honest evaluation of what worked, what broke, and real test comparisons.
2. **Relevance to the Prompt and Theme**:
   - Deeply solves a real problem for a specific loved one (Dadi / grandmother).
   - Real grandmother reaction and handover.
3. **Creativity**:
   - Cultural nuance handling (Hindi/Hinglish desi measures: *ek mutthi, chutki, katori, andaza* to grams/ml).
   - Preserving verbatim storytelling ("Dadi ki Baat").
4. **Technical Execution**:
   - Privacy-first, 100% offline local pipeline: Audio -> faster-whisper -> Ollama LLM -> Strict Zod JSON -> React editor -> Print-ready Devanagari PDF.
   - Model comparison (Qwen 2.5 vs Llama 3.1) with real benchmarks.
5. **Use of Partner Technology** (optional).
